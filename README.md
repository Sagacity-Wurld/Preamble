# USSD Simulation in R

This R script simulates a USSD (Unstructured Supplementary Service Data) session, the menu-driven short-code service used in Nigeria. It uses *312#, Globacom's Glo short code, as the example.

The program displays a menu, accepts the user's choice and returns the matching response, such as a balance or service option. It demonstrates conditional logic, user input handling and menu navigation in R.

## How to run

Open `USSD.R` in RStudio and run the script, then enter your menu choice when prompted.
